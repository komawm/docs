# Local documentation workflow

1. Read repository guidance and the affected specification. Use a named CarryCtx identity/session, a scoped task and any contract dependencies.
2. Update Markdown and affected references. Preserve unrelated work and the distinction between specification and acceptance evidence.
3. Run `just check` locally and inspect the changed text. No product build, PR, CI/CD or bot review is required here.
4. Record the results and remaining work, checkpoint, and end the session. Read task state and independently verify files before completion.
5. Apply direct repository updates only within the user's authorized scope; local checks do not authorize publication.
