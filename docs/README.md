# Specification index

The [repository index](https://github.com/komawm/docs) routes the five imported architecture/API specifications and [shared development documents](https://github.com/komawm/docs/tree/main/docs/development). Their original design status labels are preserved; implementation and runtime acceptance are recorded separately.

Koma source lives in [Koma](https://github.com/komawm/koma), Jiku scaffolding/templates in [Jiku](https://github.com/komawm/jiku), and the LuaLS snapshot in [koma-types](https://github.com/komawm/koma-types). Keep cross-repository contract changes synchronized through explicit CarryCtx tasks.
